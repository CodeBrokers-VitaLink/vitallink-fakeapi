# VitaLink API

Fake REST API for the VitaLink frontend, powered by JSON Server.

## Local

```bash
npm install
npm start
```

The API will be available at:

- http://localhost:3000/api/v1/patients
- http://localhost:3000/api/v1/alerts
- http://localhost:3000/api/v1/records
- http://localhost:3000/api/v1/interventions

## Render

Use:

- Build Command: `npm install`
- Start Command: `npm start`

Render provides the `PORT` environment variable automatically.

## Main resources

- `patients`
- `alerts`
- `records`
- `interventions`
